# Gut microbiota and colorectal cancer prognosis (SNUH cohort)

Code and input data for

> Huh J-W, Kim MJ, Kim J, Lee HG, Ryoo S-B, Ku J-L, Jeong S-Y, Park KJ, Kim D, Kim JF, Park JW.
> **Enterotypical *Prevotella* and three novel bacterial biomarkers in preoperative stool predict the
> clinical outcome of colorectal cancer.** *Microbiome* 2022;10:203.
> https://doi.org/10.1186/s40168-022-01388-8 · raw reads: NCBI SRA PRJNA859426

333 patients with primary colorectal cancer (Seoul National University Hospital) gave a stool sample
within two weeks before surgery; 16S rRNA V3–V4 amplicons were sequenced on MiSeq and the patients
were followed for progression (median 27.6 months) and death (43.6 months). The scripts here take the
ASV table and clinical metadata and rebuild every number, table and figure in the paper, plus the
exploratory diet analysis that led to the 2026 follow-up in `5-Reanalysis-2026/`.

## Repository layout
```
1-Input/      raw inputs (ASV table, taxonomy, metadata, ASV sequences, QIIME2 artifacts,
              PICRUSt2 summaries, type-strain references, 2022 diet table)
2-Figure/     figures regenerated by the scripts (SVG), named after the paper's panels
3-Output/     tables regenerated by the scripts (CSV); *.rds intermediates are git-ignored
4-Script/     00_setup.R and the six analysis scripts; run_all.R runs them in order
5-Reanalysis-2026/   diet–microbiome–prognosis follow-up (handover material, Oct 2026)
```

## How to run
Requirements: R ≥ 4.1 (developed on 4.1.0, verified on 4.6.1, Windows) with
`tidyverse`, `magrittr`, `vegan`, `survival`, `survminer`, `ggpubr`, `ggrepel`, `ggforce`, `broom`,
`Hmisc`, `data.table`, `R.utils`; optional `ggtree`/`ape` (Figure S3C).

```bash
# from the repository root
Rscript 4-Script/run_all.R          # ~15 min; 02 (Monte-Carlo CV) and 03 (bootstrap) dominate
```
Each script sources `4-Script/00_setup.R` (packages, constants, helper functions such as `km_plot()`),
reads what the previous script wrote to `3-Output/`, and can be re-run on its own.

| Script | What it does | Paper |
|---|---|---|
| `01_preprocessing.R` | rarefy to 64,604 reads (seed 123), collapse to phylum/family/genus/species, select taxa (prevalence ≥ 10 %, abundance ≥ 0.01 %), build the master table `d` (clinical + taxa + blood indices + PCoA + k-means enterotype + recurrence categories) | Methods |
| `02_screening_prognostic_bacteria.R` | enterotype / *Prevotella* survival curves; screen 79 species by log-rank and adjusted Cox; 1,000-split Monte-Carlo cross-validation; *Alistipes* re-assignment of "Bacteroides sp." | Fig. 2, S2, S3 |
| `03_microbial_hazard_score.R` | 31 candidate scores, 1,000 half-sample bootstrap, M5 score and categories, C-index against clinical markers, nested models, Table 2 | Fig. 3, Table 2, S2D-E |
| `04_community_overview_figures.R` | family barplots, PCoA + PERMANOVA for every clinical variable, Shannon diversity, enterotype vs clinical variables, host prognostic factors | Fig. 1, S1, S4 |
| `05_picrust2_pathways.R` | MetaCyc pathways (PICRUSt2) by M5 category, family contributions, pathway survival curves, CD8 correlation | Fig. 4, S5 |
| `06_diet_exploratory_2022.R` | 209 FFQ variables vs PFS/OS, Food46 vs taxa (exploratory, post-publication) | – |

Notes on the reproduction
- `vegan::rrarefy()` with seed 123 returns the identical table under vegan 2.5-7 (2021) and 2.7-6 (2026);
  `dplyr::sample_n()` consumes the random stream the same way, so the cross-validation and bootstrap
  counts match the original run digit for digit.
- The adjusted HR of the numeric M5 score (2.07) is per standard deviation of the score (continuous
  indicators were z-scaled, Methods); the per-point HR is 1.99 with the same P and C-index.
- The species screen contains "s__unidentified" (a SILVA placeholder) because it passed the published
  filter; it is kept so that n = 79 and the FDR values match the paper. It is never selected.
- The first submission adjusted the Cox screen for stage, CEA and lymphatic invasion only; the final
  covariate set (T, N, M, neoadjuvant treatment, postoperative chemotherapy, lymphatic invasion, CEA)
  came from the revision and is what the scripts implement.
- One discrepancy with the published Table 2: the CEA-high count in the M5-high group is printed as
  30 (57.7 %), whereas the data give 22 of 52 (42.3 %); the published P value (1.2e-4) corresponds
  to 22. All other cells of Table 2 (`3-Output/03_Table2_by_M5.csv`) match.

## Input data
| File | Content |
|---|---|
| `1-Input/CRC_prognosis_Metadata_333.csv` | 333 patients × 106 variables (de-identified; same variables as Additional file 1, Table S1). Sample key `NO.` |
| `1-Input/CRC_prognosis_ASV_table.csv` | 17,194 ASVs × 339 samples, DADA2 counts (6 excluded patients are dropped in script 01) |
| `1-Input/CRC_prognosis_Taxonomy.csv` | SILVA 138 (99 % OTU reference, V3–V4 trained) assignment per ASV |
| `1-Input/asv_seq.fasta` | ASV sequences |
| `1-Input/qiime2/` | QIIME2 artifacts: `table.qza`, `rep_seq.qza`, `taxa.qza`, `rooted-tree.qza` |
| `1-Input/picrust2/` | `path_abun_unstrat.tsv.gz`, `path_cov_unstrat.tsv.gz`; `derived/` holds per-sample TRFA and family contributions of the 15 reported pathways. The 873 MB stratified file is not in git; script 05 rebuilds `derived/` from it when present |
| `1-Input/tree/` | *Alistipes* type-strain alignment and tree (MEGA) used for Figure S3; 56 Prevotellaceae type-strain V3–V4 sequences |
| `1-Input/diet/` | 2022 FFQ table for 115 patients (209 variables, already energy-adjusted by the residual method) and the variable codebook |

Upstream processing (not in this repository): primer-trimmed MiSeq 2 × 300 reads → QIIME2 (DADA2
denoising) → SILVA 138 classifier trained on V3–V4 → the three CSV files above. PICRUSt2 v2.4 was run
with default settings (`place_seqs.py`, `hsp.py`, `metagenome_pipeline.py --strat_out`,
`pathway_pipeline.py --per_sequence_contrib`).

Not included on purpose: the 540-patient clinical + FFQ spreadsheet (contains names, hospital IDs and
dates), the 339-patient metadata with surgery/death dates, the `save.image()` workspaces of the original
analysis, and the serum / network side projects that were never part of the paper.
